# NEDVI Constructora — Sitio web

Sitio web público de NEDVI Constructora (nedviconstructora.com).

## Estructura

- `index.html` — la página completa (secciones, galerías, formulario de contacto y CV).
- `assets/` — fotos de proyectos, logotipo y el CV en PDF (`NEDVI_CV_Espanol.pdf`).

## Editar

- Textos y secciones: edita `index.html` directamente en GitHub (botón del lápiz) o en tu editor.
- Fotos: reemplaza el archivo en `assets/` con el mismo nombre, o agrega uno nuevo y referencia su ruta en `index.html`.
- El formulario de contacto envía por [FormSubmit](https://formsubmit.co) al correo nedviconstructora@gmail.com (hay que activarlo una sola vez desde el correo de activación que llega a esa cuenta).

## Publicación

El sitio es estático. GitHub Pages lo publica desde la rama `main` (raíz): https://nedviconstructora.github.io/nedvi-constructora-web/
